# ZILIVE
ZILIVE  Z = ZIDA  Ton direct, ton univers.  Présentation  ZILIVE est un projet d'application mobile de vidéos verticales et de diffusion en direct (LIVE), avec cadeaux virtuels, messagerie privée et possibilités de revenus pour les créateurs.
